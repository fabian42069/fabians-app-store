Privacy

No account, no ads, no tracking, no analytics. The store only talks to fabian42069.codeberg.page to fetch the list of apps and to download the apps you choose to install.

How it works

The store reads an F-Droid compatible repository and installs apps with Android's own installer. Every download is checked against its SHA-256 hash before it is installed, and all apps are signed with the same key, so updates install over the version you have.
